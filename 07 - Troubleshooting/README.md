# 07 - Troubleshooting

Méthode générale :
1. définir le symptôme;
2. déterminer l'étendue;
3. vérifier réseau / DNS / identité;
4. collecter des preuves;
5. changer une seule chose à la fois;
6. valider;
7. documenter.
