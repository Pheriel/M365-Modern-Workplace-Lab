# Objectifs professionnels

Ce lab est orienté vers un rôle **Microsoft 365 / Modern Workplace**.

## Compétences ciblées
- SharePoint Online;
- OneDrive for Business;
- Microsoft Teams;
- Entra ID;
- Intune;
- sécurité d'identité et endpoint;
- migrations on-prem → cloud;
- PowerShell;
- documentation et standardisation.

## Résultat attendu
Être capable de prendre un petit environnement de PME, de :
1. l'analyser;
2. documenter l'existant;
3. proposer une architecture cible;
4. construire un pilote;
5. migrer les données et postes;
6. valider;
7. préparer un rollback;
8. présenter clairement le résultat.

## Portfolio
Ce dépôt doit montrer :
- ce qui a été construit;
- les choix techniques;
- les erreurs rencontrées;
- les solutions;
- les procédures;
- les scripts;
- la progression.

Le but n'est pas de prétendre qu'un lab remplace l'expérience client réelle, mais de rendre l'apprentissage observable et reproductible.
