# 08 - Projets pratiques

Ces projets servent à prouver que les notions peuvent être appliquées sans suivre une vidéo pas à pas.

## Projet 01 — PME 10 utilisateurs
Construire toute l'infrastructure on-prem.

## Projet 02 — Migration File Server
Migrer des données fictives de FS01 vers SharePoint/OneDrive.

## Projet 03 — Intune
Enrôler un poste, appliquer des stratégies, déployer une application et tester la conformité.

## Projet 04 — Sécurisation Entra
MFA + Conditional Access pilote + revue des rôles.

## Projet 05 — Full Modern Workplace
Partir du lab on-prem et arriver à une architecture moderne documentée.

Chaque projet doit inclure :
- objectif;
- design;
- exécution;
- validation;
- problèmes;
- rollback;
- leçons apprises.
