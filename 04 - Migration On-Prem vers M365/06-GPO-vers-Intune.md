# GPO → Intune

## Inventaire
Pour chaque GPO :
- nom;
- objectif;
- paramètres;
- cible;
- impact.

## Classer chaque paramètre
- Settings Catalog;
- Endpoint Security;
- Configuration Profile;
- script;
- non requis dans le nouvel environnement;
- aucune équivalence simple.

## Challenges
Migrer au moins :
- une stratégie de sécurité;
- une stratégie Windows Update;
- une configuration OneDrive;
- une configuration navigateur.

## Principe
Le but n'est pas de recopier 100 % des GPO. Certaines deviennent inutiles dans une architecture moderne.
