# Migration FS01 → SharePoint

## Jeu de données
Utiliser uniquement des fichiers fictifs :
- Word;
- Excel;
- PDF;
- sous-dossiers;
- noms longs;
- plusieurs niveaux d'arborescence.

## Étapes
1. inventorier la source;
2. nettoyer les données inutiles;
3. créer la destination;
4. configurer les groupes;
5. tester les permissions;
6. faire une migration pilote;
7. comparer source/destination;
8. tester avec plusieurs utilisateurs;
9. corriger les erreurs;
10. simuler un cutover.

## Validation
- fichiers présents;
- utilisateurs autorisés accèdent;
- utilisateurs interdits refusés;
- nombre et volume cohérents;
- processus impactés identifiés.

## Journal
Chaque erreur de migration doit être documentée :
- symptôme;
- cause;
- correction;
- prévention.
