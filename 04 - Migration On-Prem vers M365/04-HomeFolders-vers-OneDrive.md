# Dossiers personnels → OneDrive

## Objectif
Migrer les fichiers personnels de travail vers OneDrive.

## Avant migration
Identifier :
- emplacement actuel;
- taille;
- fichiers ouverts;
- chemins trop longs;
- extensions problématiques;
- fichiers partagés qui devraient plutôt aller dans SharePoint.

## Après migration
Valider :
- présence dans OneDrive;
- sync;
- Files On-Demand;
- droits;
- versioning;
- restauration.

## Known Folder Move
Étudier et tester le déplacement contrôlé des dossiers connus lorsque la licence et le lab le permettent.

## Challenge
Déterminer quels fichiers doivent aller dans OneDrive et lesquels doivent aller dans SharePoint.
