# Udemy — Microsoft 365 Administration: Mastering SharePoint & Teams

## Rôle de ce cours dans le lab

Ce cours sert de **source principale pour la partie collaboration / administration Microsoft 365**, surtout :

- Microsoft 365 Admin Center;
- SharePoint Online;
- Microsoft Teams;
- OneDrive for Business;
- Microsoft 365 Groups;
- permissions et partage;
- notions d'identité Microsoft Entra ID;
- automatisations et usages connexes selon les modules du cours.

Le cours ne remplace pas les labs dédiés à **Intune, Autopilot, Defender, Conditional Access avancé ou Azure**. Ces sujets sont traités séparément dans le repo.

## Informations du cours

- Titre : **Microsoft 365 Administration: Mastering SharePoint & Teams**
- Durée affichée : environ **25,5 heures**
- Curriculum affiché : **252 éléments**
- Focus principal : **Microsoft SharePoint**
- Description Udemy : administration M365 autour de SharePoint, Teams, OneDrive et Microsoft Entra ID.

## Méthode d'utilisation

Pour chaque module utile :

1. regarder la leçon;
2. refaire la manipulation dans le tenant de lab;
3. prendre des notes avec ses propres mots;
4. ajouter une validation concrète;
5. provoquer au moins un scénario d'erreur lorsque pertinent;
6. documenter la résolution;
7. refaire plus tard sans vidéo.

## Critère de réussite

Une leçon est réellement acquise lorsque je peux :

- expliquer **pourquoi** la fonction existe;
- la configurer dans mon tenant de lab;
- vérifier que ça fonctionne;
- identifier où dépanner si ça échoue;
- expliquer comment ce sujet s'intègre dans une migration réelle de PME.
