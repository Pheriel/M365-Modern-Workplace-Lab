# Nomenclature

## Serveurs
- `DC01` : Domain Controller + DNS
- `FS01` : File Server

## Clients
- `CLIENT01`
- `CLIENT02`
- `CLIENT03`
- `PHYCLIENT01`

## Groupes AD
- `GG-` : Global Group
- `DL-` : Domain Local Group

Exemples :
- `GG-Comptabilite`
- `GG-Direction`
- `DL-FS-Comptabilite-RW`
- `DL-FS-Direction-R`

## GPO
- `GPO-Workstations-Baseline`
- `GPO-MapDrives`
- `GPO-WindowsUpdate`
- `GPO-Defender`
- `GPO-Firewall`

## Principe
Un nom doit permettre de comprendre rapidement **quoi**, **où** et **pourquoi**.
