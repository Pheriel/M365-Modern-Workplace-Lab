# FS01 — File Server

## VM
- 2 vCPU
- 4 Go RAM
- 60 Go disque OS
- 100 Go disque DATA
- Windows Server 2025 Desktop Experience

## Renommer
```powershell
Rename-Computer -NewName "FS01" -Restart
```

## Réseau
```text
IP  : 192.168.70.20
DNS : 192.168.70.10
```

## Tests avant join
```cmd
ping DC01
nslookup lab.local
nslookup DC01
```

## Joindre le domaine
```powershell
Add-Computer -DomainName lab.local -Credential LAB\Administrator -Restart
```

Déplacer ensuite FS01 dans `LAB-Servers`.

## Disque DATA
Créer :

```text
D:\Shares
├── Commun
├── Comptabilite
├── Direction
├── Employes
└── TI
```

## Partages
- `\\FS01\Commun`
- `\\FS01\Comptabilite`
- `\\FS01\Direction`
- `\\FS01\Employes`
- `\\FS01\TI`

## Permissions d'exercice
Alice Comptabilité :
- RW Comptabilité
- RW Commun
- aucun accès Direction

Charlie Direction :
- RW Direction
- RW Commun

Bob Employé :
- RW Employes
- RW Commun
- aucun accès Comptabilité/Direction

## Validation
Depuis un client :
```cmd
dir \\FS01\Commun
dir \\FS01\Comptabilite
```

Tester également des refus d'accès attendus.
