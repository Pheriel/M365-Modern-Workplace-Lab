# Least Privilege

## Objectifs
- séparer compte utilisateur et compte admin;
- limiter les rôles;
- éviter Global Administrator comme solution par défaut;
- revoir régulièrement les droits.

## Lab
Créer :
- un compte utilisateur standard;
- un compte admin;
- plusieurs rôles limités.

Tester ce qu'un rôle peut et ne peut pas faire.

## Documentation
Pour chaque rôle :
- justification;
- détenteur;
- durée;
- services impactés.
