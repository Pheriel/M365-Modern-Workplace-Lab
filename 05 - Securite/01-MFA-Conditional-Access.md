# MFA + Conditional Access

## MFA
Tester avec des comptes fictifs du lab.

## Conditional Access
Méthode prudente :
1. créer un groupe pilote;
2. utiliser Report-only lorsque disponible;
3. prévoir un compte de secours;
4. analyser l'impact;
5. activer seulement après validation.

## Exercices
- MFA obligatoire pour un groupe pilote;
- appareil conforme vs non conforme;
- examiner les sign-in logs;
- provoquer un refus contrôlé.

## Modèle mental
Conditional Access :
**qui + ressource + conditions + contrôle d'accès**
