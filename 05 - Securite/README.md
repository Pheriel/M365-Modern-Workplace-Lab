# 05 - Sécurité

Sujets :
- MFA;
- Conditional Access;
- least privilege;
- comptes admins séparés;
- comptes de secours;
- Defender;
- BitLocker;
- revue des rôles;
- partage externe.

## Principe
La sécurité doit être testable et réversible dans le lab.

Ne jamais créer une politique qui risque de verrouiller tous les comptes administrateurs sans stratégie de récupération.
