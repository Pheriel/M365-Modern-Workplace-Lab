# 09 - Documentation professionnelle

Écrire comme si un autre technicien devait reprendre le projet demain sans contexte verbal.

Templates :
- [Audit client](template-audit-client.md)
- [Plan de migration](template-plan-migration.md)
- [Procédure](template-procedure.md)
- [Changement](template-changement.md)
- [Rollback](template-rollback.md)
- [Validation](template-validation.md)

Une bonne documentation explique :
- pourquoi;
- quoi;
- comment;
- comment valider;
- comment revenir en arrière.
