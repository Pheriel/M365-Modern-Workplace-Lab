# Compliance Policies

## Objectif
Comprendre la différence entre :
- configuration;
- conformité;
- accès conditionnel.

## Exercices
Créer une politique mesurable, par exemple :
- BitLocker requis;
- version OS minimum;
- exigences de sécurité compatibles avec le trial.

## Test
1. cibler le groupe pilote;
2. synchroniser;
3. vérifier l'état;
4. provoquer un échec contrôlé;
5. corriger;
6. observer le retour à l'état conforme.

## Documentation
Noter les délais de reporting : le cloud n'est pas toujours instantané.
