# Configuration Profiles

## Exercices
Créer plusieurs profils simples :
- Windows settings;
- navigateur;
- OneDrive;
- sécurité;
- restrictions de lab.

## Méthode
Pour chaque profil :
1. objectif métier;
2. paramètres;
3. groupe cible;
4. résultat attendu;
5. validation;
6. rollback.

## Pilote
Créer un groupe :
```text
GRP-INTUNE-PILOT
```

Ne jamais cibler tout le tenant pendant les premiers tests.

## Challenge
Créer un profil visible sur le poste, le retirer, puis confirmer le rollback.
