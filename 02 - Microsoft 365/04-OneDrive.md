# OneDrive for Business

## Règle simple
- fichiers personnels de travail → OneDrive;
- fichiers d'équipe → SharePoint / Teams.

## Exercices
- sync;
- Files On-Demand;
- partage;
- versioning;
- corbeille;
- Known Folder Move;
- accès depuis plusieurs postes.

## Migration
Créer un jeu de données personnel fictif puis planifier sa migration vers OneDrive.

## Validation
- fichiers présents dans le cloud;
- sync saine;
- permissions correctes;
- partage testé;
- suppression/restauration testée.

## Challenge
Expliquer pourquoi mettre les données d'un département dans le OneDrive du gestionnaire serait une mauvaise conception.
