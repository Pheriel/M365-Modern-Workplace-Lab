# SharePoint Online

## Scénario
FS01 possède :
- Commun
- Comptabilite
- Direction
- Employes
- TI

Objectif : concevoir une structure SharePoint adaptée aux usages, sans reproduire automatiquement l'arborescence SMB.

## Exercices
- créer un site d'équipe;
- créer des bibliothèques;
- configurer propriétaires/membres/visiteurs;
- tester héritage et permissions uniques;
- partager en interne;
- tester le partage externe dans le lab;
- versioning;
- corbeille;
- synchronisation.

## Questions avant migration
Pour chaque partage :
- qui est propriétaire?
- qui doit lire?
- qui doit modifier?
- les données sont-elles collaboratives?
- Teams est-il utilisé?
- la synchro locale est-elle nécessaire?
- y a-t-il des fichiers obsolètes?

## Challenge
Créer un site Finance et démontrer :
- accès membre;
- accès lecture;
- refus d'accès;
- restauration d'une version précédente.
