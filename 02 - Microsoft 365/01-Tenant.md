# Tenant Microsoft 365

## Avant d'activer un trial
Avoir déjà :
- DC01 fonctionnel;
- FS01 fonctionnel;
- utilisateurs/groupes;
- plusieurs postes;
- données fictives à migrer.

Ainsi, la période de trial sert réellement à la pratique cloud.

## À documenter
- nom du tenant;
- domaine `.onmicrosoft.com`;
- comptes administrateurs;
- licences attribuées;
- services disponibles.

## Centres d'administration
Explorer :
- Microsoft 365 admin center;
- Entra admin center;
- Intune admin center;
- SharePoint admin center;
- Teams admin center;
- Exchange admin center;
- Defender portal.

## Règles
- MFA sur les comptes admins;
- compte admin séparé du compte utilisateur;
- utiliser uniquement des identités fictives;
- ne jamais publier d'identifiants/secrets dans GitHub.
