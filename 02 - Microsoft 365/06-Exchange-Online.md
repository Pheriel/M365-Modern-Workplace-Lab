# Exchange Online — notions

Même si le focus est Modern Workplace, connaître :
- mailbox utilisateur;
- shared mailbox;
- Microsoft 365 Group;
- distribution group;
- alias;
- Full Access;
- Send As;
- DNS mail de base.

## Lab
Créer une boîte partagée fictive :
```text
support@<tenant>.onmicrosoft.com
```

Ajouter deux utilisateurs et tester :
- ouverture;
- envoi;
- différences avec une mailbox utilisateur.
