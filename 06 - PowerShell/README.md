# 06 - PowerShell

Scripts de lab et commandes utiles.

## Dossiers
- AD
- Windows
- Microsoft365

## Règles
Les scripts doivent être :
- commentés;
- sans secrets;
- testés dans le lab;
- accompagnés d'un exemple d'utilisation;
- idempotents lorsque possible.

Commencer petit : automatiser ce qui a déjà été fait manuellement et compris.
